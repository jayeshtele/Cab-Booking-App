# Cab Booking App

A responsive cab booking front end built with React, Vite, Tailwind CSS, React Router, Redux Toolkit, and Lucide icons.

## Features

- Book ride page with pickup, drop, schedule, passengers, payment, route distance, cab selection, and fare estimate.
- Redux-powered booking state with trip confirmation and active offer selection.
- Routed pages for Book, Trips, Offers, and Support.
- Dynamic browser tab titles and a cab-themed favicon.
- Mobile-first layout with desktop navigation and bottom mobile tabs.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
